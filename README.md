### 📋 Giới thiệu hệ thống
- **Dữ liệu:** Báo cáo tổng hợp chất lượng siêu âm mối hàn (UT) đa tuần của các nhà máy thuộc Tập đoàn CS Wind.
- **Tính năng chính:**
  - So sánh trực quan tỉ lệ khuyết tật hàn theo từng tuần / tháng / dự án.
  - Phân tích cơ cấu 5 loại khuyết tật: Slag (Xỉ), Lack of Fusion (Không ngấu), Incomplete Penetration (Không thấu), Porosity (Rỗ khí), Crack (Nứt).
  - Bảng vinh danh thợ hàn chất lượng cao và giám sát thợ có mét lỗi cao.
  - Bộ lọc tương tác đa chiều: Nhà máy (BP1, BP2), Foreman, chủng loại máy hàn, dải chiều dày tôn.
